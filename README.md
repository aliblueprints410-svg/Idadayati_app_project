# تطبيق إعداديتي - Idadayati App 🎓✨

منظومة وتطبيق التعليم المهني والإعدادي الذكي في العراق (الفرع الصناعي، التجاري، الزراعي، الحاسوب وتقنية المعلومات، والفنون التطبيقية).

---

## 🌟 نظرة عامة (Overview)
تطبيق **إعداديتي** هو منصة تعليمية ومهنية متقدمة موجهة لطلبة وأساتذة المدارس المهنية والإعدادية، تم بناؤه بأحدث تقنيات **Flutter** مع نظام هجين متطور يدعم العمل على:
- 📱 **Android App (APK)**
- 💻 **Windows Desktop (EXE)**
- 🌐 **Progressive Web App (PWA)**

---

## 🎨 الهوية البصرية وتجربة المستخدم (UI/UX Design)
- **الخلفية النقية:** خلفية بيضاء خالصة (`#FFFFFF`) لجميع الصفحات والقوائم لراحة العين أثناء الدراسة.
- **الألوان الثانوية الملكية:** 
  - الأزرق السماوي/الملكي العراقي (`#1E40AF` / `#2563EB`)
  - الذهبي الإمبراطوري الفاخر (`#D97706` / `#F59E0B`)
- **أيقونات متخصصة:** تم تصميم أيقونات عصرية للمختبرات، الورش الفنية، الأقسام المهنية، والامتحانات الوزارية.

---

## 🚀 الميزات التقنية والأمنية (Key Features)
1. **عزل كامل ومستقل للبيانات:** قاعدة بيانات خاصة للمدارس المهنية مع كودات تفعيل مستقلة لكل مدرسة ورمز لكل أستاذ.
2. **العمل بدون إنترنت (Offline Capability):** دعم كامل للعمل والتخزين المحلي حتى عند انقطاع الإنترنت، مع مزامنة لحظية فور استعادة الاتصال.
3. **أمان عالي (Enterprise Security):** تشفير محلي للبيانات الحساسة، حماية بروتوكول HTTPS/WSS، وسياسات RLS صارمة في Supabase.
4. **تكامل متقدم مع الإشعارات:** دعم نظام OneSignal لإرسال تبليغات فورية لطلبة الورش والمختبرات والمحاضرات.

## 🛠️ متطلبات التشغيل والتطوير (Getting Started)

### 1. إعداد المتغيرات البيئية
انسخ ملف `.env.example` إلى `.env` وقم بملء البيانات الخاصة بك:
```bash
cp .env.example .env
```

### 2. تثبيت الحزم (Dependencies)
```bash
flutter pub get
```

### 3. بناء المنصات (Build Commands)
- **بناء تطبيق الأندرويد (APK):**
  ```bash
  flutter build apk --release
  ```
- **بناء تطبيق الويب (PWA):**
  ```bash
  flutter build web --release --pwa-strategy=offline-first
  ```
- **بناء تطبيق ويندوز (Desktop EXE):**
  ```bash
  flutter build windows --release
  ```

## 📂 هيكلية المشروع (Project Structure)
- `lib/core/`: إعدادات الثيم، الألوان، خدمات الشبكة والتخزين المحلي.
- `lib/features/`: الشاشات ولوحات التحكم (الطلاب، الأساتذة، الأقسام المهنية، الدرجات والواجبات).
- `assets/`: شعارات التطبيق، الأيقونات التخصصية، والخطوط العربية.
- `web/`: إعدادات تطبيق الويب التقدمي (PWA Manifest, Service Worker).
- `windows/`: تكوين ومكتبات نسخة سطح المكتب لويندوز.
- `android/`: تكوين ومكتبات نظام أندرويد (com.alibp.idadayati).
